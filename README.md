# PSPInitializer

A tool that creates the PSP root directory structure on Memory Cards and miniSD cards.

## How to Use

1. Download the Linux or Windows version from [Releases](../../releases).
2. Run the program.
3. Choose your Memory Card or miniSD card.
4. Press **OK**.
5. PSPInitializer will automatically create the required files and folders for you.

## Features

- Supports Linux and Windows.
- Automatically creates the PSP directory structure.
- Simple and easy to use.
